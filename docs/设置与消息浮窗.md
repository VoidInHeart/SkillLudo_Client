# 设置与消息浮窗（2026-09-12）

大厅的“技能图鉴”位于“创建房间 / 加入房间”下方，个人资料头像仍在右上角。登录页原有图鉴入口保留。

所有页面左上角提供齿轮设置入口，包括登录、大厅、房间、对局，以及聊天、技能、技术暂停和赛后窗口。设置中的“聊天消息浮窗”使用可点击、可拖动的滑动开关，默认开启；选择保存在当前设备/浏览器，刷新或重新打开页面后保留。

- 关闭会立即移除当前浮窗，并停止房间、对局的新消息浮窗；聊天记录与收发消息不受影响。
- 重新开启只显示之后收到的新消息，不补弹关闭期间的消息。
- 技能按钮闪烁、挂机倒计时、技术暂停和胜者窗口仍正常显示。
- 棋局消息浮窗缩至最多 270×46 棋盘界面单位，浅蓝背景，填充不透明度为 155/255，最多显示三条；消息停留 30 秒。长消息最多显示两行，完整内容可在聊天窗口查看。房间浮窗保留原有尺寸与样式。

## 验证

```powershell
npm run check
npm run check:tests
npm test
npm run build:web
# 独立终端保持 npm run preview:build 运行
npm run verify:settings
npm run verify:viewport
npm run build:wechat
npm run verify:wechat
```

新增 `settings-smoke.mjs` 在桌面 DPR 2 与手机模拟 DPR 3 中实际点击头像、图鉴、齿轮、关闭按钮和开关，并拖动桌面开关。验证所有上述场景的设置可访问性、卡片边界、浮窗尺寸/透明度/上限、关闭即时清理、继续保存聊天记录、重新开启不回放、消息过期，以及旋转和整页刷新后的持久化。

该脚本加载真实页面后使用隔离的棋局和账号显示夹具，拦截游戏命令，不创建真实账号或提交测试棋局。设置与输入交互为实际 Cocos 指针事件。它不能替代微信真机或真实网络对局验收。

本机结果：`docs/verification/settings-result.json` 与 `settings-*.png`；两种设置场景、7 种既有适配环境均通过，零浏览器错误。客户端 22 项回归和类型检查通过。Web/微信构建成功，微信横屏、30 文件共 3,580,803 字节；未进行微信真机验收。服务端和协议 4 均不变。

公网复验可设置 `$env:SKILLLUDO_WEB_URL = 'http://81.70.145.148'` 后执行 `npm run verify:settings`，结果写入 `published-settings-*`；发布记录见阶段日志。
