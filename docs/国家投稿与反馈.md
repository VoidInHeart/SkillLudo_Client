# 国家投稿与反馈

主页头像下新增“DIY新的国家卡片”，设置内新增“反馈”。两者需要登录注册账号。国家可编辑 1–6 个技能，用下拉框选择普通、限定、CD、觉醒；CD 类型额外填写冷却规则。其余内容均为文字，提交前可预览所有技能。

服务端记录认证账号，并将内容整理为 JSON 附件，发往 `skillludoadapter@163.com`。国家邮件主题为 `<国家名称>技能设计`。提交成功表示邮件服务器已接收；失败或待确认时，内容仍有数据库记录，请保留编号。投稿用于后续开发，当前不会自动成为可用阵营。

草稿按账号和表单类型保存在当前设备，关闭窗口或切换横竖屏不丢失输入。同一内容重试保持相同提交编号，不重复发信；更改内容后预览会生成新编号。窗口使用 Cocos 控件，可参与微信小游戏构建。

回归命令：`npm run verify:submissions`（需本地 7459 Web 预览与 3101 测试后端）。测试用真实鼠标、触摸、键盘输入，覆盖桌面/DPR3 手机、下拉框、两项技能切换、旋转、预览、重复点击、同编号重试与设置反馈。提交被拦截，不发送测试邮件。结果和截图位于 `docs/verification/submission-*`。

服务端部署、JSON 格式、错误状态、限流和 SMTP 环境配置见后端仓库 `docs/国家投稿与反馈.md`。无需在前端或 GitHub Secret 填写邮箱授权码。
